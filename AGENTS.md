# Whisper — agent notes

- The Rust side is zero-dependency; the ONE external component is whisper.cpp, and it is never committed. It is pinned in pins.txt, fetched + SHA-256-verified by fetch.sh / fetch.ps1 into vendor/ (gitignored), and built as static libraries by build.rs via CMake. Bump = version + hash together in pins.txt, then re-run the e2e proof.
- Two build modes are both first-class: engine-absent (fresh checkout — FFI compiles, unit tests pass, engine calls return WS_ERR_NOT_SUPPORTED) and engine-present. The WinDevKit gate must stay green in engine-absent mode; never make the host gate depend on the ~90 MB source+model download.
- The whisper.h struct mirrors in src/engine.rs (WhisperContextParams / WhisperFullParams) are ABI-locked by compile-time size/offset assertions probed from the pinned header with a C program. If a whisper.cpp bump trips them, re-probe with the C compiler and update deliberately — never silence the asserts.
- CMake config is load-bearing: GGML_NATIVE=OFF (the DLL must run on machines other than the builder), GGML_OPENMP=OFF (no libgomp/vcomp runtime dependency; ggml's own threadpool instead), BUILD_SHARED_LIBS=OFF, PIC on. build.rs only builds the engine when host == target; Windows linking is proven by CI (ci.yml), whose e2e step transcribes the JFK sample with the pinned tiny.en model and asserts "fellow Americans".
- Deviations from the sibling DLLs, both deliberate: (a) the release profile does NOT set panic = "abort" — every FFI entry point guards with catch_unwind and the guard only works when panics unwind to the boundary; (b) error code 3 is ERR_NOT_FOUND per the shared win-common 0–6 convention (CrashKit's 3 = NOT_INSTALLED is the documented odd one out, not this crate).
- Model files are user-supplied ggml binaries; never commit one. The tiny.en model in pins.txt is a TEST FIXTURE only (the e2e proof), not a runtime dependency.
- Claims discipline (SQLiteSuperBuild rule): the README's feature list must not exceed what the tests check. The e2e test checks one English clip with tiny.en; do not claim language coverage, accuracy figures, or speed numbers that nothing measures.
